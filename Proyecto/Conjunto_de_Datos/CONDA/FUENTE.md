# FUENTE: dataset CONDA

- Nombre completo: CONDA (CONtextual Dual-Annotated dataset for in-game
  toxicity understanding and detection)
- URL de origen: https://github.com/usydnlp/CONDA (repositorio público
  oficial; los archivos están en la carpeta `data/`)
- Institución: NLP Group, University of Sydney
- Fecha de descarga: 2026-08-31
- Método de descarga: `git clone https://github.com/usydnlp/CONDA.git` y
  copia de `data/*.csv` y `resources/lexicon_refined_1209.csv`
- Licencia y condiciones: dataset académico publicado junto con el artículo
  de ACL-IJCNLP 2021; hay que citar el artículo al usarlo.
